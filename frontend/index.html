LinkedIn Extension

Use the Chrome extension to save leads from LinkedIn profiles and search results directly to your pipeline.

  1. Install the Chrome extension from the LinkedIn Tools page.
  2. Open a LinkedIn profile or search results page, click the extension icon.
  3. The extension extracts the person's name, title, company, and LinkedIn URL.
  4. Configure your Supabase URL and API key in the extension popup, then click Save to ShowToShip.
Need the Supabase URL or anon key? Contact your admin.

Guides

How to use the ShowToShip system

📋 Getting Leads Into the System

Option A — Scraper (recommended for supported sites):

  1. Go to Tradeshows and click the Scrape button next to a show, or click + New Scrape Job on the All Leads page.
  2. Type the show name (it auto-creates a new show if one doesn't exist).
  3. Paste the exhibitor list URL(s) — one per line. Supported domains: mapyourshow.com, a2zinc.net (and custom A2Z domains).
  4. Toggle LLM Extraction on for unsupported sites (uses AI to parse the page). Keep it off for supported sites.
  5. Toggle Deep Scrape if you want to follow each exhibitor's detail page for more data.
  6. Toggle Find Emails to hunt for email addresses on company websites (slow on large lists).
  7. Click Run Scraper — results appear in the table automatically.

Option B — Manual CSV Import:

  1. Click Import CSV in the All Leads toolbar.
  2. Select a CSV file with columns like company name, contact, email, phone, website, etc.
  3. Map the detected columns to the right fields in the modal, then confirm.

Option C — LinkedIn Extension:

  1. Install the Chrome extension from the LinkedIn Tools page.
  2. Open a LinkedIn profile or search results page, click the extension icon.
  3. The extension extracts the person's name, title, company, and LinkedIn URL.
  4. Configure your Supabase URL and API key in the extension popup, then click Save to ShowToShip.
📊 Managing Leads
  • Filter by Show: Click a show name on the Dashboard (upcoming shows) or Tradeshows page to jump to all leads for that show.
  • Pipeline Stages: Use the left sidebar pipeline filters (New → Contacted → Qualified → Opportunity) to track progress.
  • Assign: Click a lead to open the detail panel, then pick a team member from the Assign dropdown.
  • Bulk Actions: Select multiple leads with checkboxes, then use Bulk Assign or Bulk Delete.
  • Letter Bar: Click a letter to filter leads alphabetically by company name.
  • Duplicate Finder: Click Duplicates to list leads that share an email address or LinkedIn URL, so you can merge or delete them.
  • Export: Click Export CSV in the sidebar to download every lead matching your current filters. The file opens cleanly in Excel, accents included.
🧹 Clearing Data
  • Clear leads per show: On the Tradeshows page, click Clear Leads next to a show to remove all leads from that show only.
  • Delete individual leads: Open a lead's detail panel and click Delete at the bottom.
  • Bulk delete: Select leads with checkboxes, click Bulk Delete, then confirm.

⚠ Deletions are permanent and cannot be undone.

🔧 Configuration

Go to Settings in the sidebar to configure:

  • GitHub Connection: Personal Access Token + repo name — used if you want to commit scrape results.
  • Supabase Database: Project URL and Anon Key — connects the app to your Supabase backend.
  • Admin Function URL: Edge Function for user management (admin only).
  • Team Members: Add names so you can assign leads to specific people.
🔧 Running Scrapers via GitHub Actions

For large or automated scrapes, use the GitHub Actions workflow:

  1. Go to the repo's Actions tab → Scrape Exhibitors workflow.
  2. Click Run workflow and fill in the show name and URL(s).
  3. The workflow runs the Playwright scraper in the cloud and saves results directly to Supabase.
  4. The SUPABASE_KEY secret must be set to the service_role key (not anon) for INSERT permission.

Supported sites: MapYourShow, A2Z Events (including custom domains), SMM (API), EuroNaval.

🔍 Finding Contacts

The Find Contacts feature uses Hunter.io to discover email addresses and names for a company based on its website domain.

  1. Go to Settings → Contact Finder and paste your Hunter.io API key. Get a free key at hunter.io/api-keys (25 requests/month).
  2. Open any lead's detail panel — only leads with a website work.
  3. Click Find Contacts — Hunter searches the domain and returns names, titles, and email addresses.
  4. Review the results. Click Use next to a contact to save their name, title, and email to the lead.
  5. The saved contact info appears in the table's Contact column and the lead's detail panel.

💡 Filter by Has Website in the toolbar to see only leads eligible for contact discovery.

🤖 AI Assistant

The 🚢 AI Assistant helps you research companies without leaving ShowToShip. Click the ship button in the bottom-right corner to open the chat.

What you can ask:

  • "Tell me about Acme Corp" — looks up company info from your leads database.
  • "Find contacts for a company" — suggests web search results and verifies against local data.
  • "Which leads look promising?" — analyzes your pipeline for high-priority opportunities.
  • "Compare these two companies" — side-by-side comparison from your data.
  • "Any setting" — choose the AI provider in Settings. Default uses the server key (no setup).

Per-lead shortcut: Open a lead's detail panel and click Ask AI about this company to pre-fill the chat with context.

🎨 Customizing Columns & Filters

ShowToShip gives you full control over what you see in the leads table.

Show / Hide Columns:

  • Click the Columns button in the toolbar to toggle any column on or off.
  • Your preferences are saved in your browser and persist across sessions.
  • Columns available: Company, Contact, Show, Country, Category, Products, Email, Status, Assigned, Priority.

Filtering leads:

  • Search bar — type any text to search across all lead fields.
  • Keyword filter — search within company name, products, description, category, and industry.
  • Dropdown filters — narrow by Show, Status, Team Member, Email, Source, Country, Website, or Contact.
  • Letter bar — click a letter to jump to companies starting with that letter.
  • Column headers — click any header to sort asc/desc.
📊 Understanding the Dashboard

The dashboard gives you a high-level snapshot of your pipeline and activity.

  • Total Leads — every lead in the system across all shows.
  • New — leads that haven't been touched yet. Start here.
  • Contacted — leads you've reached out to.
  • Qualified / Opportunity — promising leads worth pursuing.
  • Recent Leads — the last 10 leads added, with quick actions.
  • Upcoming Shows — shows sorted by date; click any to see its leads.
🏷️ Lead Statuses & Pipeline

Each lead moves through stages in your sales pipeline. Change a lead's status from its detail panel.

  • New — just imported, no action taken yet.
  • Contacted — you've reached out (email, call, LinkedIn).
  • Qualified — they're interested and fit your criteria.
  • Disqualified — not a fit (wrong industry, budget, etc.).
  • Opportunity — active deal in progress.
  • Closed — won or lost; pipeline is done.

Priority levels (High / Medium / Low) help you sort and focus. Use the Priority column in the table to see at a glance which leads matter most.

Bulk updates: Select multiple leads with checkboxes, then click Status or Assign to update them all at once.

📤 Exporting Data

You can export your leads at any time.

  • Export All: Click Export Excel in the left sidebar to download every lead matching your current filters as an .xlsx file.
  • Export Selected: Check specific leads with the checkboxes, then click Export Sel. to export only those.
  • CSV Import: Use Import CSV to bring in leads from spreadsheets or Sales Navigator exports.

💡 The export respects your current filters — if you've filtered by show or status, only matching leads are exported.

👥 Adding Someone to the Team

If you're an admin — go to Admin in the sidebar, click + Add User, enter their email and pick a role. That's the whole job.

They receive an email with an invite link. Opening it brings them straight to a set your password screen; once they choose one, they're signed in. Until then they show as Invited on the Admin page.

  • They never got the email: check spam. Then use Resend on their row.
  • "The link doesn't work": invite links expire. Resend issues a fresh one.
  • They're stuck at the sign-in box: they've probably opened the app directly instead of via the invite link. Have them use Forgot your password? — it does the same job.
  • Roles: User can see and manage every lead. Admin can additionally add and remove people. You can change someone's role any time from the Admin page.

Removing someone revokes their access immediately. Leads assigned to them are kept.

🔍 When a Scrape Finds Too Few Exhibitors

The scraper follows pagination automatically — paste the first page of a directory and it will walk the rest, including "load more" buttons and infinite scroll. The job log reports each page as it's collected, so you can see how far it got.

  • Got a fraction of the exhibitors? The site may split its list behind filters (by hall, by category, by letter). Paste each of those URLs on its own line — duplicates are merged automatically.
  • Got zero? Turn on LLM Extraction and re-run. That reads the page with AI instead of CSS selectors.
  • Still zero? The site likely needs its own config. These sites have one and give the best results: SMM Hamburg, MapYourShow, A2Z Events, Euronaval.
  • Missing emails and contacts? That's a separate step — turn on Find Email Addresses, or use Find Contacts on an individual lead.
